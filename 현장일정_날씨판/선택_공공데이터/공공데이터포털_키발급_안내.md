# 공공데이터포털 기상청 API 키 받기 · 시험하기

> 대상 : `선택_공공데이터` 예제(api/kma.js)를 돌려 보려는 사람 · 교재 **부록 G** 와 같은 내용
> 키가 실제로 동작하기까지 길게는 1~2시간 걸리므로 **실습 전날까지 신청**해 두세요.
>
> **KMA_KEY 가 뭔가요?** 따로 받는 키가 아니라, 공공데이터포털에서 받은 **「일반 인증키」에 예제 코드가 붙인 이름**입니다 (KMA = Korea Meteorological Administration, 기상청).

---

## 1. API 페이지 찾기

**바로가기 : https://www.data.go.kr/data/15084084/openapi.do**

검색으로 찾을 때 헷갈리는 두 가지

- 이름이 바뀌었음 : 「기상청_단기예보 ((구)_동네예보) 조회서비스」 → 지금은 **「기상청_단기예보 조회서비스」**
- 검색 결과가 **파일데이터 / 오픈 API / 표준데이터** 칸으로 나뉨 → **「오픈 API」 칸**의 항목을 눌러야 활용신청 버튼이 보임

## 2. 활용신청

1. data.go.kr 회원가입 · 로그인
2. 위 페이지에서 조금 내리면 「관심목록에 추가」 옆 **파란 [활용신청]** 버튼
3. 신청서 작성

| 항목 | 이렇게 |
|---|---|
| 활용목적 | **웹 사이트 개발** |
| 설명 | 아래 문구 그대로 붙여 넣기 |
| 상세기능 | 모두 체크 (예제는 그중 **초단기실황 getUltraSrtNcst** 사용) |
| 라이선스 표시 | 「동의합니다」 체크 → 활용신청 |

설명 문구 예

```
교육 실습용 웹 서비스 개발.
현장 일정과 지역 날씨(기온·풍속·강수)를 함께 보여 주는 '현장일정 날씨판'을 만들어,
바람·비 등 기상 조건에 따라 야외·고소 작업 일정의 진행 여부를 판단하는 기능을 구현하고자 함.
비상업적 교육 목적이며, 조회 결과는 화면 표시에만 사용함.
```

개발계정은 **자동 승인**됩니다.

## 3. 인증키 복사

**마이페이지 → 데이터활용 → Open API → 활용신청 현황 → 「기상청_단기예보 조회서비스」** 클릭 → 일반 인증키

- 2026-10-23 확인 : 포털은 **「일반 인증키」 한 줄만** 보여 줌 (끝이 `%3D%3D` 처럼 끝나는 Encoding 키)
- 이 한 줄을 **통째로** 복사해 `.env` · Vercel 에 그대로 넣으면 됨 — kma.js가 `%` 가 있으면 그대로, 없으면(Decoding 키) 알아서 인코딩함
- 같은 화면 「참고문서」의 **[다운로드]** = 활용가이드 zip (6절 격자 엑셀이 들어 있음)

## 4. 키 보관

| 어디서 돌리나 | 키를 넣는 곳 |
|---|---|
| 내 PC | 프로젝트 맨 위 `.env` 파일 → `KMA_KEY=복사한키` (줄 이름이 꼭 `KMA_KEY` — 다른 키 이름 줄에 넣으면 코드가 못 찾음) |
| Vercel 주소 | 프로젝트 → Settings → Environment Variables → `KMA_KEY` 추가 → **Redeploy** |

- `.env` 는 `.gitignore` 에 있어 GitHub에 안 올라감. `.env.example` 은 이름만 적힌 견본
- 키는 **채팅 · 코드 · GitHub · 공유 드라이브에 넣지 않음**

## 5. 주소창에서 먼저 시험

`(인증키)` 자리에 복사한 일반 인증키, `base_date` 에 오늘 날짜를 넣어 크롬 주소창에 붙여 넣기

```
https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/getUltraSrtNcst?serviceKey=(인증키)&pageNo=1&numOfRows=10&dataType=JSON&base_date=20261027&base_time=1000&nx=60&ny=127
```

- `base_time` : 매시 정각 자료가 40분쯤 나옴 → 지금이 10시 40분 전이면 `0900` 처럼 한 시간 전
- 성공 : `"resultCode":"00"` 과 함께 기온 **T1H** · 풍속 **WSD** · 1시간 강수량 **RN1** 값이 보임

## 6. 격자값 nx, ny

기상청은 위도 · 경도가 아니라 전국을 **5km 격자**로 나눈 번호로 예보합니다.

- 찾는 법 : API 페이지 아래 **참고문서** → 활용가이드 zip → **「격자_위경도.xlsx」** 에서 시 · 군 · 구 · 읍면동 이름 검색
- 예제 kma.js에 넣어 둔 값

| 지역 | nx | ny |
|---|---|---|
| 서울 종로구 (위 시험 주소) | 60 | 127 |
| 세종 | 66 | 103 |
| 대전 | 67 | 100 |
| 태안 | 48 | 109 |
| 보령 | 54 | 100 |

- 위경도만 알면 AI에게 "위경도를 기상청 격자(nx, ny)로 바꾸는 함수 만들어 줘" 라고 요청 (활용가이드에 변환식 있음)

## 7. 막힐 때

| 화면에 나온 것 | 뜻 · 할 일 |
|---|---|
| `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 키가 아직 반영 안 됨 → 1~2시간 뒤 다시. 키를 덜 복사했는지(끝의 `%3D` 까지) 확인 |
| `KMA_KEY 가 없음` (내 PC) | `.env` 줄 이름이 `KMA_KEY` 인지 확인 |
| `SERVICE_ACCESS_DENIED_ERROR` | 다른 API를 신청함 → 신청 현황에서 서비스 이름 확인 |
| `NO_DATA` (resultCode 03) | `base_date` · `base_time` 이 미래이거나 너무 옛날 → 한 시간 전 정각으로 |
| `{"error":"Vercel 환경변수 KMA_KEY 가 없음"}` | Vercel 환경변수 추가 후 **Redeploy** 안 함 |
| `지원하지 않는 지역` | kma.js 의 GRID 에 그 지역 nx, ny 추가 |
