# 선택 · 키가 필요한 API — 공공데이터포털 기상청 초단기실황

> 03 단원 강사 시연 + 원하는 사람만. Open-Meteo(키 없음)로 이미 날씨판은 완성됨.
> 10/23 강사 키로 실제 호출 확인 (resultCode 00) · 남은 리허설 : Vercel 환경변수

## 왜 따로 하나
| | Open-Meteo | 공공데이터포털 |
|---|---|---|
| 키 | 없음 | 있음 (회원가입 → 활용신청 → 일반 인증키) |
| 어디서 부르나 | 화면 코드(브라우저)에서 바로 | **서버 함수(api/kma.js)**에서만 — 화면에 키를 두면 누구나 봄 |
| 키 보관 | – | Vercel 환경변수 `KMA_KEY` (GitHub에 안 올라감) |

## 순서
1. **https://www.data.go.kr/data/15084084/openapi.do** 로그인 → [활용신청] → 마이페이지에서 **일반 인증키** 복사
   (검색으로 찾으면 '기상청_단기예보 조회서비스' — 결과 중 「오픈 API」 칸. 승인은 바로 나지만 키가 동작하기까지 시간이 걸릴 수 있음 — 미리 신청)
   → 화면 순서 · 신청서 문구 · 시험 주소 · 격자값은 `공공데이터포털_키발급_안내.md` / 교재 부록 G
2. 이 폴더의 `api/` 를 내 프로젝트 맨 위에 복사 → push
3. Vercel → 프로젝트 → Settings → Environment Variables → `KMA_KEY` 추가 → **Redeploy**
4. 주소 뒤에 `/api/kma?region=세종` → `{"temp": …, "wind": …}` 가 나오면 성공

## 확인할 것
- `.env` 파일은 `.gitignore` 에 있어 올라가지 않음. `.env.example` 은 키 이름만 적힌 견본
- 포털 일반 인증키(끝이 `%3D`)를 그대로 넣으면 됨 — kma.js가 Encoding · Decoding 키를 둘 다 받음
- 화면 코드에서는 `fetch('/api/kma?region=세종')` 처럼 **내 주소의 함수**를 부름
